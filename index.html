Add findings

Layer a finding onto claims already loaded — matched by claim ID or by provider. Doesn't touch anything else.
Match specific claims: {"rule":"R001","label":"Duplicate Claim","severity":"Critical","match":{"claimIds":["CLM-012"]},"detail":"...","duplicateOf":"CLM-011"}

Or sweep a whole provider: {"rule":"R005","label":"Provider Utilization Volume","severity":"High","match":{"providerNpi":"2384710655"},"detail":"..."}

Rule codes: R001 Duplicate · R002 NCCI · R003 High-Dollar · R004 Data Integrity · R005 Provider Utilization Volume · R006 Coding Distribution / Peer Comparison.

Reset batch

Permanently deletes every claim, finding, and provider analysis row for one batch from the backend. This cannot be undone. Local sample data on this page is not affected — use "Reset to sample data" in Load Data for that.
Base URL and anon key are remembered for this browser tab only — never saved, never sent anywhere but your own Supabase project.
